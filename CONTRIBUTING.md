# Contributing

Thanks for your interest in MyBaby.

The code is public so that parents and anyone else can see exactly how the app handles a family's data.
It isn't an open-source project: it's licensed under the [PolyForm Strict License 1.0.0](LICENSE.md),
which doesn't allow changes or redistribution, so pull requests aren't accepted.

You can still help:

- **Found a bug?** [Open an issue](../../issues/new/choose) with the steps to reproduce it.
- **Have an idea?** Open a feature request and describe what would make your nights easier.
- **Found a security or privacy problem?** Please email mybaby@manhattin.com instead of opening an issue.
  See [SECURITY.md](SECURITY.md).
- **Need help with the app?** See the [support page](docs/support.html) or email
  mybaby@manhattin.com.
